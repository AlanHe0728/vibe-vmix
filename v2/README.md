# 第二版 · 足球转播包装

独立的第二版，按用户提供的 2025/26 英超转播宣传片重做。原版继续使用原来的启动方式；第二版尚未取代原版，也未更新已有便携包或 Release。

## 启动

双击项目根目录的 `启动第二版.bat`。使用独立的 8124 端口，可与原版同时运行。

- 控台：`http://localhost:8124/control/panel.html`
- 预览与布局：`http://localhost:8124/control/preview.html`
- vMix 网页输入：`http://localhost:8124/titles/graphics.html`，画布 1920×1080。

首次启动将原版的本地球队、名单、队徽和字体复制为第二版配置，原文件不变；第二版时钟暂停，布局使用新版默认位置。此后两个版本各自保存，第二版不会跟随原版自动同步。需要切换比赛时可继续使用 TXT 导入导出。

第二版配置保存在 `v2/control/state.json`，已加入 Git 忽略。不要将此文件放进公开分发包。关闭第二版的服务窗口即可停止第二版。

## 多人换人

进入「比赛操作 → 换人」，选择球队及第一组下场、上场球员，点击「添加一组换人」继续添加。一次支持 1–11 组。

- **仅保存**：保存整个换人列表，不改变场内名单，不播出。
- **执行**：执行已保存列表，不保存当前草稿。
- **保存并执行**：保存并一次执行当前列表。

整批校验场内/场外身份和重复选人，全部通过才更新名单与播出。任何一组无效或保存失败，整批不执行。执行后再次执行相同列表会被拒绝，防止重复换人。实际换人会更新场内选项，不改赛前首发记录，也不修改比分。

## 视觉与动画

紫白平面信息块、俱乐部配色的自适应比分条、时钟标签、清楚的号码与姓名栏。使用本地开源 Outfit 字体，中文使用系统字体或用户上传字体。自定义赛事标识可替换比分中间的足球图标；不附带英超狮子商标、球员肖像或球队照片。

计时器和阵容沿上边缘展开，事件栏沿左边缘展开；名单行与多人换人行分次进入，退场沿原路径收回。支持修改停留与进退场时长，减少动态效果偏好会关闭位置移动。预览保留坐标、对齐、安全框、吸附、局部隐藏等工具。

参考视频未包含完整双队名单，其阵容排版是依照相同视觉语言的延展。

开源字体许可见 `titles/assets/fonts/OFL.txt`。第二版使用本机现有 Node.js，缺少时自动使用 Windows 自带 PowerShell，无需另配开发环境。
