# 足球转播包装第二版

网页足球包装，支持比分、名单、比赛事件和多人换人。

保留完整项目目录，双击根目录的 `启动第二版.bat`。

- [控制台](http://localhost:8124/control/panel.html)
- [预览与布局](http://localhost:8124/control/preview.html)
- [vMix 网页输入](http://localhost:8124/titles/graphics.html) · 1920 × 1080

在「比赛操作 → 换人」添加多组球员，选「保存并执行」一次处理。比赛资料保存在 `v2/control/state.json`，与原版分开。
