# 转播包装 · Live Bridge

面向 Windows After Effects 2022（22.x）及以上、支持 CEP 的版本的开发版扩展。连接转播包装工作台 2.0 Beta 的可选「AE 直播连接」模块。无需 npm 安装；所需 Node 来自 AE 自带 CEP。

## 安装与连接

1. 保留此文件夹的完整内容。关闭 AE，使用 PowerShell 在本文件夹执行 `powershell -ExecutionPolicy Bypass -File .\安装插件.ps1 -EnableUnsignedExtensions`。安装脚本复制插件到当前用户的 Adobe CEP 目录，并只在传入该参数时启用 CSXS 9–12 的未签名开发扩展。
2. 这是未签名开发版；启用开发扩展也会允许其他未签名 CEP 插件加载。关闭时把 `HKCU\Software\Adobe\CSXS.<版本>\PlayerDebugMode` 设为 `0`。本项目没有静默运行安装脚本或修改系统配置。
3. AE 首选项 → 脚本与表达式 → 启用「允许脚本写入文件和访问网络」。重启 AE，从「窗口 → 扩展（旧版）/扩展 → 转播包装 · Live Bridge」打开面板。不同 AE 版本菜单名称可能不同。
4. 启动工作台，启用「AE 直播连接」，把该模块页面中的地址与密钥填入插件。仅接受 `127.0.0.1` 的 HTTP 地址。密钥保存在程序的 `data/ae-live/pairing.json`；不要对外分享。
5. 在 AE 选中合成并连接。可点击「创建直播示例合成」开始。示例会新建合成，不替换已有工程。

不支持 CEP 的 AE 版本不能使用此开发包；manifest 的版本范围表示请求加载范围，不能作为每个 AE 版本已实测的证明。

## 直播控件

- 文本图层名称以 `LIVE:` 开头，可从工作台和插件修改文字。
- 名称以 `LIVE:` 开头的图层上的 Slider Control、Color Control、Checkbox Control 分别映射为数值、颜色、开关。可用「标记选中图层为 LIVE」处理已有图层。
- 修改通过明确的“应用”按钮发送，保留 AE 撤销组。不修改未暴露图层。锁定图层、文本关键帧，以及带关键帧/表达式的效果控件会拒绝修改并显示原因。
- 图层 ID、名称、效果类型和索引均需匹配；AE 中重命名、重排或切换合成后应重新读取。旧合成的命令不会改到新合成。
- 工作台可添加 `LIVE_IN`、`LIVE_HOLD`、`LIVE_OUT` 合成标记。这些是制作定位标记，不会自动生成 NDI、循环表达式或完整进出场调度。

## 实时修改与画面刷新

打开「持续生成当前画面」后，插件按设置的目标刷新率请求 AE `saveFrameToPng`，上传透明 PNG 到本机工作台。工作台将最新画面提供给 vMix 网页输入；画面须点击“上屏”后显示。直接在 AE 中修改暴露控件也会被定期读取。

“推进时间轴”按经过的时间计算工作区帧，超时直接跳到当前时间，不堆积旧帧。最多一个 AE 操作执行；目标 1/2/5/10 fps 不等于实际帧率，面板显示最近一帧渲染耗时。AE 的同步脚本渲染会占用 AE 主线程；复杂合成或长渲染期间，插件不能保证即时响应。当前通道无音频、无 NDI/Spout、无 25/50/60 fps 广播帧率保证，也不含 Adobe 专有渲染引擎。

关闭持续画面就停止生成；断开连接 15 秒后网页画面自动隐藏。AE 的背景工作不能被网页按钮强行中断；若操作已进入执行，清空队列只取消尚未执行的命令。重新连接会清空旧队列，执行结果不确定的命令标为“需核对”，不自动重放。

## 动画播放与缓存

1. 选好 AE 工作区，在 AE 保存或准备好内容，在插件或工作台点击“渲染当前工作区”。
2. 输入本机 AE 真实存在的输出模块模板名称。默认 `Lossless with Alpha` 只是初始填写值；本地化 AE/自定义模板名称需自行调整。透明度、编码和文件扩展名由 AE 模板决定，模板应输出兼容 vMix 的 MOV。
3. 插件保留已有渲染队列项的勾选状态，临时添加本次合成并渲染，结束后移除临时队列项。取消或失败会报告错误，不添加成品。
4. 完成后缓存出现在工作台。添加到 vMix，填写 vMix 输入名或编号，再使用播放、暂停/保持、从头播放、循环、上屏和下屏。

已完成的缓存保持不变，制作下一版时 vMix 可继续播放旧版。新缓存需由操作员显式检查并上屏；程序不把未完成的渲染替换到正在播出的输入。流畅直播动画使用此路径，交互画面适合更新较慢的图文内容。

## 当前验证范围

本机未安装 After Effects / vMix。已验证 Node 连接服务、密钥与来源校验、命令顺序、合成匹配、队列合并、重复回执、断连恢复、PNG 发布和模拟 vMix 调用。ExtendScript 使用模拟 AE 对象测试，CEP 面板静态与模拟通信测试不等于 AE 真机测试。

使用前需在实际 AE/vMix 上确认：CEP 能加载、中文路径、JSON 脚本加载、文字/颜色/滑块/开关、分辨率恢复、PNG Alpha、实际帧率、输出模板、MOV 解码、原队列恢复、长渲染期间连接恢复。正式播出前请以实测结果决定可用场景。
