1.00×

Ulanzi D200 实体按键

使用 API Request 控制比分、进球、计时、判罚和名单。先保存内容，再按 D200 上屏。

未保存的文字不会传给 D200。D200 配置页可复制请求地址、查看推荐按键并下载配置清单。

vMix 叠层 显示/隐藏 (可选)

比分/文字/动画由本面板写入 state.json 驱动，完全不需要连接 vMix。 这里只是【可选】的显示/隐藏小工具（触发入场/出场动画），需 vMix 在运行且 API 端口(默认8088)正确。 连不上 vMix 不影响内容，可忽略本卡片。
先【刷新输入列表】选择该模板输入，再用【显示/隐藏】把它放到叠层通道；也可直接用 vMix 的过渡/叠层操作。
