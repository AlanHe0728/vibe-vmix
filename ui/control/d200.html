D200 按键配置

返回控制面板连接服务器…

在 Ulanzi Studio 的应用商店安装 API Request，拖到 D200 按键后，按右侧字段填写。先配置推荐的 12 个常用键。Ulanzi Studio 和足球包装服务器均须保持运行。

选择按键功能

配置清单用于填写 API Request 字段。更多按键可放到 Ulanzi Studio 的其他页面或文件夹。

正在读取功能…

状态轮询（可选）

在插件中勾选“根据响应设置按键图片”和“定期轮询 URL 状态”；需要状态图标时上传匹配、未匹配两张图片。

开启轮询时，务必填写单独的状态 URL。动作 URL 仅接受 POST；状态 URL 的 GET 只读取信息。

正在读取比分…

试按会立即改变当前比赛。进球键加 1 分并播放庆祝；重播进球只播放动画。事件和名单读取控制面板已保存的内容。
