# 使用说明

[返回首页](../README.md)

## 接入 vMix

启动控台后，在设置的设备连接页面复制联合上屏地址，在 vMix 中添加网页浏览器输入，画布设为 1920×1080。

控制台、预览和上屏页使用同一个本地服务。默认端口是 8123；便携版遇到端口占用时会换用其他端口，以程序中显示的地址为准。

播出期间保持程序运行。最小化窗口不影响服务，关闭主窗口会退出程序并暂停时钟。

## 球队和名单

在名单准备页面填写双方队名、队色和队徽。队名离开输入框或按 Enter 保存，队色修改后点击保存队色。

在总名单中导入 TXT、CSV、TSV、Excel 文件，也可以粘贴名单。每人一行，例如：

```text
1 张三 (GK)
10 李四 (中场) (C)
12 王五
```

`(GK)` 表示门将，`(C)` 表示队长，同一个人可以同时标记。Excel 中的位置、队长和守门员列也会保留。

勾选需要首发的球员，其余自动归为替补。可以添加球员、修改 GK 和队长标记、搜索或删除条目；撤销删除可恢复最近删除的一人。这些操作先保留为草稿，点击保存双方首发才会写入。恢复已保存首发可撤回当前草稿。

标准 11 人制比赛请各选 11 人，也可以按其他赛制选择人数。单独编辑首发与替补中保留了四份名单的编辑和单独上屏功能。

## 比分和计时

顶部的主队 +1、客队 +1 只修改比分，不播放动画。点击中央比分可以更正或归零。

比赛时钟在各个页面都可以开始、暂停。在计时设置中选择正计时或倒计时，设置时间或使用快捷按钮。比赛时钟与下方的独立计时器分别控制。

比赛状态只有进行中和暂停。中场休息、比赛结束等在阶段中选择，选择阶段不会重置时钟。

### 自动切换半场

在计时设置中启用自动切换，填写每半场时长和中场休息时长。

正计时按累计时间切换，例如每半场 45 分钟时，在 45:00 进入中场、90:00 结束比赛。倒计时在每半场到 0 时切换。

启用休息结束后自动开始下半场，服务会在休息结束后启动下半场。休息设为 0 会直接切换。不启用时，需要手动开始下半场。

自动切换默认关闭，需要补时时可以关闭它。即使控台页面关闭，只要服务还在运行，自动切换仍会执行；退出便携程序会暂停时钟并取消待开始的休息计时。

## 进球、判罚和其他事件

在比赛操作中选择事件，填写球队、球员等内容。球员可以从名单中选择，也可以输入号码匹配。

| 按钮       | 作用                                     |
| ---------- | ---------------------------------------- |
| 保存并执行 | 保存当前填写的内容并播出                 |
| 仅保存     | 保存内容，不播出，不执行换人或重置计时   |
| 执行       | 使用上次保存的内容，忽略当前未保存的修改 |

判罚和发球需要先选择类型。

进球默认不加分。如果已经在顶部加过分，直接播放进球事件即可。需要同时加分时，在画面内容与加分选项中勾选同时为所选球队 +1，再点击保存并执行。成功后该勾选会取消，之后执行已保存的进球不会重复加分。

球员信息条的标题可以修改，例如填写最佳球员。

独立计时器的执行按钮会按已保存的时长重新设置并显示。开始、暂停和加减时间不会修改已保存的时长。

## 换人

先选择球队，再选择场内的下场球员和场外的上场球员，使用保存并执行或执行完成换人。

仅保存会保存换人信息，不改变场内名单。实际执行后，球员选项和场内、场外名单会更新，赛前首发记录保留。相同的一组换人再次执行会被拒绝。

## 保存比赛配置

在名单准备顶部点击导出本场配置，可以把双方队名、队色、队徽、首发和替补保存为一个 TXT 文件。导出包含当前名单草稿，队徽使用已保存的图片。

下一场比赛点击读取配置文件即可载入。文件通过校验并保存后，场内名单恢复为首发。

配置文件只包含双方球队资料，不包含比分、时钟、主题或布局。换比赛时需要另行清零比分、设置时间。读取有误或保存失败时会保留原资料。

文件格式和手写示例见[比赛配置文件格式](MATCH_CONFIG.md)。

## 预览和画面设置

在画面设置中修改主题、颜色、图片和字体。打开预览与布局，可以拖动图形、调整坐标和缩放，也可以使用安全框、网格吸附和对齐工具。

预览比例、安全框和辅助网格只影响编辑显示。最终播出画布由 vMix 决定，建议使用 1920×1080。

顶部的比分条和名单按钮控制已保存内容的显示，不会提交当前草稿。

## 备份和升级

便携版数据位于程序目录：

- `data/state.json` 保存比赛、名单、图片、字体和布局。
- `data/browser` 保存界面和预览偏好。

退出程序后复制整个 `data` 文件夹即可备份。升级时，将旧版 `data` 带入新版目录，不要用新版空白数据覆盖旧数据。换电脑时可以复制整个程序文件夹。

源码运行的数据保存在 `control/state.json`；第二版使用 `v2/control/state.json`。这些文件不会提交到仓库。

## 无法启动时

先确认便携包已完整解压，并且程序目录可以写入。如果下载的是分卷，需要先合并再解压。

查看 `data/desktop-error.log`，反馈问题时附上版本和操作步骤。已有数据损坏时程序会提示，不会自动清空比赛。

D200 的配置方法见[按键设置](D200_SETUP.md)。
