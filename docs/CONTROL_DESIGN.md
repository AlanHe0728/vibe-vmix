# 控制台视觉约定

控制台是操作工具：保证选项、文字、选中状态和焦点容易识别。本约定覆盖控制台五个分组、D200 配置、预览按钮及编辑工具栏。观众端转播图形由根目录 DESIGN.md 规定。

用户最新要求：按钮和卡片透明，开启/选中为白底蓝字，关闭/未选中为透明玻璃、灰色辅助；网页背景使用用户提供的 D:\Download\478422.jpg。保持现有布局与操作，不加循环动画或额外开发服务。

主色 `#0068c5`，文字 `#172431`，辅助灰 `#253343`。普通操作按钮静止时为透明玻璃，按下立刻白底蓝字，松开恢复；持续选项在真实状态保存成功后保持白底蓝字，不把复制、重置、执行等单次操作伪装成开关。原 blue/green/yellow/red 类名保留兼容，但统一材质。红黄牌、结束、清除等通过文字表达；球队、赛事强调色等色块仍表示真实比赛数据。

文字输入、闭合下拉、数值、滑杆容器、上传框、文本区、按钮和卡片全部覆盖玻璃材质。单行控件统一 44px、胶囊圆角；多行文本区 20px，卡片 26px。小框填色 8%、模糊 12px；按钮填色 6%，hover 18%，薄白边高光与底部灰蓝反光；卡片填色 10%、18px 模糊，背景曲线在卡片内部可见。选中项 94% 白色填色、蓝字，不再出现蓝底白字。公共材料 token 在 control/glass-theme.css，控制台布局在 panel-layout.css；D200 与预览通过 aux-controls 类复用材质，编辑栏样式只作用于 #editbar。

开关保留原生 checkbox，46×28px；内部 26×22px 透明玻璃滑块，切换时移动 14px。动画倍率保留原生 range，蓝色进度/灰色轨道与 38×28px 透明胶囊滑块，进度终点按滑块中心计算。键盘 Home/End/方向键、原生拖动、实时倍率文字和应用后保存行为不变。选中 D200 按钮的标题与小字均蓝色。

背景图按原文件复制为 control/assets/console-background.jpg，以固定 cover 方式显示，叠加 40% 白色薄层保证暗部文字可读；图片未压缩或编辑，不写入 state.json，也不引用外部文件路径。控制台、D200 配置页和预览页共用背景，观众端保持透明。正文保持实色，轮廓与焦点用蓝灰。hover 阴影不改变尺寸与位置。顶部导航滑块使用透明玻璃和蓝色标签，不继承普通启用按钮的白底；切换时轮廓短暂粘连变形，保留可打断、键盘即时切换和减少动态效果支持。按钮按下立即反馈，松开时短暂恢复，不叠加持续动效。

原生可定制下拉列表保留顶层显示、optgroup、键盘选择与滚轮滚动，不因换肤改写球员匹配逻辑。旧浏览器回退原生 select；降低透明度或增加对比度时，所有框与卡片改实底并取消模糊。验证使用隔离比赛数据，桌面和手机一起检查五个分组与展开菜单，不动真实 state.json。

已保存素材在 44px 上传框内显示文件名，长文件名省略并可悬停查看全文。原生文件选择按钮继续工作，不尝试伪造本地文件路径；无历史文件名的素材显示“已保存”。图片缩略图与说明放在上传行下方，避免挤压文件框或让清除按钮垂直错位。字体只显示已保存名称，保留同一行字族名输入。Excel 多工作表选择使用现有玻璃 select，导入后出现；只改变名单草稿。

液态导航滑块只由一个 SVG 轮廓绘制透明渐变与边缘高光，背景模糊来自父导航。用于动画的全宽宿主不再绘制背景、阴影或第二层模糊，避免圆角外出现浅色方框。减少透明度/增加对比度时，直接将轮廓填色改为白色并加深边缘。

预览页新增可收起的 310px 玻璃布局侧栏，控件位于缩放画布之外，保持可读字号和 44px 操作高度。X/Y 成对、六个对齐按钮按三列两行排布；比例、安全框、网格、临时显示分别成组。桌面侧栏与画布并排，窄屏作为可收起的浮层，隐藏滚动条但保留滚轮滚动。输入框允许选择文本，持续开关保留键盘操作与白色启用状态。旁边说明坐标/缩放同步播出、辅助线/比例/临时隐藏仅预览，不增加外部服务。
