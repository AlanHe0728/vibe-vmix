# 更新记录

## 2.0.0-beta.2

- 预览与布局改为浅色工作台：上方模块与栏目选择、中央画布、右侧可收起的属性面板。
- 增加未上屏栏目的排版预览、单栏预览、预览显隐、大小滑杆与拖动缩放、键盘微调、六向对齐。
- 增加构图比例、95% / 90% 安全框、网格与吸附，以及透明棋盘、球场示意和深浅背景。
- 排版示例和监看偏好只影响 PVW；位置与大小仍需确认应用后才改变播出。

## 2.0.0-beta.1

- 新增可选的舞台节目与 AE 直播连接模块，足球包装作为独立模块按需加载。
- 歌词按行保存，支持直接选句、上一句、下一句和字幕下屏；编辑后的内容不会自动覆盖正在播出的句子。
- 统一独立预览窗口，提供模块标签、组合预览和 PVW / PGM 显示方式；位置调整先预览，确认后应用到播出。

## 2.0.0-beta.1

2026-11-10 · Beta 测试版

- 增加按需加载的舞台、足球和 AE 直播连接模块。
- 增加 Windows WebView2 桌面工作台，以及舞台节目单、四套模板和素材导入。
- 增加 AE CEP 连接插件与动画缓存工作流；AE / vMix / NewBlue 真实环境联调仍未完成。
- 保留 1.1.0 作为历史稳定版本；本 Beta 的 Windows 安装包需从源码构建。

## 1.1.0

2026-10-29 · [下载](https://gitee.com/alanhe0728/vibe-vmix/releases/tag/v1.1.0)

- 增加比赛配置 TXT 导入和导出，保存双方队名、队色、队徽、首发、替补、位置及 GK 和队长标记。
- 增加总名单选择、球员添加、删除和单步撤销。
- 比赛时钟在顶部常驻，支持自定义半场时长、中场休息和自动切换。
- 事件操作分为保存并执行、仅保存、执行。顶部加分只修改比分，不播放动画。
- 控台和预览改为白底界面，比赛状态保留进行中和暂停。
- 修正球员条标题、队名同步和已保存素材文件名的显示。
- 便携包内置运行环境，发布时不携带用户比赛数据，升级时保留已有配置。

  1.0.1 和 1.0.2 为本地迭代，本次合并为 1.1.0 发布。

2026-10-14 · [下载](https://gitee.com/alanhe0728/vibe-vmix/releases/tag/v1.0.0)
