# 比赛配置文件

在控制台「名单 → 比赛配置文件」中导出 TXT；另一台电脑或下一场比赛可直接读取同一文件。

文件保存双方名称、球队颜色、内嵌队徽、首发、替补，以及每位球员的号码、姓名、位置、队长和守门员标记。TXT 为 UTF-8 编码的 JSON 文本，可用记事本编辑。队徽随文件携带，无需把原图片放在同一目录。

## 使用方法

1. 填好两队名称、颜色和四份名单，在「画面设置」上传队徽。
2. 点击「导出本场配置」。导出包含当前名单输入框的草稿和已保存的队徽，不会修改正在使用的比赛数据。
3. 点击「读取配置文件」，选择 TXT。文件通过校验并保存成功后，队名、队徽、名单及事件选择框一次更新，场内球员恢复为文件中的首发；之前准备的事件球员清空，方便为新比赛重新选择。

比分、计时器、比赛阶段、状态、主题及画面布局继续沿用当前控制台设置。下一场开赛前可自行清零比分、设置时间。导入不触发进球、换人等事件，也不会改变栏目的显示开关。读取有误或保存失败时保留原资料。

## 名单里的标记

```text
1 张三 (GK)
2 李四 (后卫)
10 王五 (中场) (C)
12 赵六 (GK) (C)
```

- `(C)`、`(队长)`、行尾 `*` 或 `#` 标记队长。
- `(GK)`、`(门将)`、`(守门员)` 标记守门员，支持中英文括号。队长和守门员可同时标记。
- `(中场)`、`(前锋)`、`(CB)` 等记录位置；自定义位置可写为 `[位置:左边前卫]`。选择球员或输入号码匹配后，球员条的位置输入框也会跟随填写。
- Excel/CSV 表头支持「号码」「姓名」「位置」「队长」「守门员」，列顺序可调整。「位置」填写 GK/门将即可识别守门员；标记列填写 `是`、`1` 或 `true`，未标记可留空或填 `否`。
- 观众端完整与单独名单均显示 GK 和队长标记；控制端场内/场外和球员选择框也能看到标记。

## 手写配置

可点击「下载格式示例」获取完整示例。必填结构如下，`starters` 为首发，`substitutes` 为替补。`position` 为位置；`captain` 和 `goalkeeper` 使用 JSON 布尔值 `true` / `false`。

```json
{
  "format": "vibe-vmix-match",
  "version": 1,
  "teams": {
    "home": {
      "name": "主队",
      "color": "#C8102E",
      "logo": { "data": "", "filename": "" },
      "starters": [
        { "number": "1", "name": "张三", "position": "GK", "goalkeeper": true },
        { "number": "10", "name": "李四", "position": "中场", "captain": true }
      ],
      "substitutes": []
    },
    "away": {
      "name": "客队",
      "color": "#00529F",
      "logo": { "data": "", "filename": "" },
      "starters": [
        { "number": "1", "name": "王五", "position": "GK", "goalkeeper": true, "captain": true }
      ],
      "substitutes": []
    }
  }
}
```

无需队徽时让 `logo.data` 为空；导入后会清除该队当前队徽。需要队徽时，建议先上传图片再用控制台导出，软件会自动生成图片的 data URI。单张队徽建议压缩到 4 MB 以下，整个配置文件上限为 16 MB。每份首发/替补最多 120 人，号码使用 0–999；同队可有不同姓名的同号球员，但不能重复填写同一号码和姓名。

格式只读取约定的球队与名单字段。向 TXT 添加比分、时钟命令或动画 tick 不会使其执行。
